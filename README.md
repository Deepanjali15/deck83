# Deck 83

A retro cassette-style music player. Play built-in chiptune tracks or add your own songs.

Live site: https://stalwart-florentine-ee5f6c.netlify.app

## Features
- Email accounts that work on any device (Supabase)
- Three built-in chiptune tracks
- Add and delete your own songs (saved on your device)
- Spectrum meter and spinning tape reels

## Setup
1. Create a Supabase project and copy the Project URL and anon key into config.js.
2. Deploy index.html, player.html and config.js to Netlify.
3. Set the Site URL in Supabase to your Netlify address.
